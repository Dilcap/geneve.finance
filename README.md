geneve.finance

Site vitrine statique (HTML/CSS) pour Genève Finance, sur le modèle de lyon.finance.
Les pages intérieures sont générées par `node build.js` (templates/head.html + pages/*.html + templates/foot.html) ; les fichiers <slug>/index.html produits sont commités.
Déployable directement sur Vercel (aucune config build nécessaire).
